# TRACE THE HACKER
### A Cybersecurity and Automata Arcade

TRACE THE HACKER is an interactive cybersecurity-themed game developed using the concepts of Formal Languages and Automata.

The project demonstrates the practical application of Deterministic Finite Automata (DFA) through three cybersecurity-based missions.

## Game Levels

1. **Phishing Awareness** – Identify a phishing-related attack sequence.
2. **Malware Outbreak** – Investigate a malware-related attack.
3. **Data Breach** – Trace a sequence leading to data exfiltration.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- JFLAP

## Project Structure

- `server.py` – Flask backend and API routes.
- `engine.py` – DFA processing and sequence validation.
- `static/` – Frontend files.
- `automata/` – JFLAP DFA implementations.
- `requirements.txt` – Python dependencies.

## Installation and Execution

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd TRACE-THE-HACKER
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python server.py
   ```

5. Open your browser and visit:

   http://127.0.0.1:5000

## Key Features

- Three cybersecurity-based missions.
- DFA-based sequence validation.
- Interactive event cards.
- State transition path display.
- Limited probes and star-based scoring.
- Level progression.
